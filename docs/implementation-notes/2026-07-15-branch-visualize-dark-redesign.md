# branch-visualize: HTML デザイン刷新 + 自動レイアウト内蔵

日付: 2026-07-15 (JST)

## 背景

生成される HTML 図の見た目が GitHub ライト風の固定配色で洗練されておらず、type 別固定 3 カラム + LLM の座標計算式レイアウトのため接続線が中央に収束して束になっていた。参考デザイン（ダークネイビー背景のアーキテクチャ図）に寄せたトンマナへ刷新し、接続線の重なりを解消した。

## 設計判断（ユーザー確認済み）

| 論点 | 決定 |
|---|---|
| カラーテーマ | ダーク固定（参考画像準拠）。ライト/ダーク切替はしない |
| 接続線の重なり解消 | テンプレート JS に自動レイアウトを内蔵（外部ライブラリ同梱・生成側計算式の改良は不採用） |
| スコープ | 3 フォーマット全部（mermaid / d2 の配色もダークトーンに統一） |

## 実装内容

### assets/diagram-template.html（全面改修）

- **ダークテーマ**: 背景 `#0b0f16`、ノードは「暗い塗り + 低輝度の色付き枠」（高彩度ベタ塗りを廃止）。ノード名は monospace、type ラベルは letter-spacing 付き小ラベル、詳細パネルはダークガラス（backdrop-blur）
- **自動レイアウト（Sugiyama 系・依存ゼロ・素の JS 約 120 行）**:
  1. DFS で後退エッジを検出しレイアウト計算上だけ反転（循環対応）
  2. 最長パス法で依存の深さ → カラム（x）を決定
  3. 複数カラムをまたぐエッジにダミー点を挿入し、バリセンタ法 4 スイープで交差削減
  4. ノード辺上に接続点をポート分散し、線の始点・終点の重なりを防止
- **生成契約の変更**: GRAPH JSON から `x` / `y` を廃止。生成側（LLM）は nodes / edges を渡すだけになり、座標計算ミスで図が崩れる経路を排除
- **インタラクション追加**: hover で接続エッジ・隣接ノードをハイライトし他を減光（150ms ease-out、`prefers-reduced-motion` 対応）。初期表示はコンテンツ全体へのフィット

### references/format-guide.md

- 共通カラー節をダークパレット（塗り / 枠 / 文字の 3 値）に刷新
- mermaid 雛形: ダークチップ型 classDef + 丸型ノード + subgraph の `grp` クラス + `linkStyle default`
- d2 雛形: ルート `style.fill` で背景ダーク化 + `classes`（`border-radius` 含む）+ glob `(** -> **)[*]` でエッジ色指定（d2 v0.6 以降前提と明記）
- HTML 節: スキーマから x/y を削除、「レイアウト計算」節を削除、エッジの向き・循環許容の記述を追加

## 検証結果

- テンプレート内 JS: `node --check` で構文 OK
- HTML: 21 ノード・24 エッジ（収束エッジ・複数カラムまたぎ含む）のサンプルで実生成し、ヘッドレス Chrome のスクリーンショットで確認。依存ベースの左→右レイヤー配置になり、旧版の「中央への収束バンドル」が解消。4 ステータス（added / modified / removed / unchanged）の視認性も確認
- mermaid 雛形: mermaid@11（CDN）+ ヘッドレス Chrome で実レンダリングし、構文・見た目を確認
- **d2 雛形は未検証**: ローカルに `d2` CLI が無くレンダリング確認ができていない。使用構文（`classes` / ルート `style.fill` / glob 接続スタイル）は d2 v0.6+ の公式機能だが、初回利用時に `d2` CLI で表示確認を推奨

## トレードオフ・補足

- 自動レイアウトは Sugiyama 完全版ではない（座標割当は等間隔スタック + カラム垂直センタリング。優先度法による y 座標最適化は未実装）。ノード数 40〜100 規模の想定用途では十分と判断
- 孤立ノード（エッジ無し）は最左カラムに配置される。専用クラスタ表示は過剰設計と判断し見送り
- mermaid は GitHub 上で背景色を制御できないため「ライト背景に載るダークチップ」として設計（format-guide に明記）
- 旧スキーマ（x/y 付き JSON）が渡された場合も座標は無視されるだけで動作する（後方互換）
