# disk-space-cleanup

使用端末のディスク空き容量を確保するスキル。開発系キャッシュを読み取り専用でスキャンし、削除して良い理由とリスクを添えてリストアップ → ユーザー確認後に削除する。

## 使い方

```
/disk-space-cleanup
/disk-space-cleanup -p ~/Downloads も調べて
```

または「ディスクが足りない」「容量を空けたい」と伝える。

## 動作内容

1. `df -h` で現在の空き容量を記録
2. 読み取り専用スクリプトで開発系キャッシュをスキャン（npm/pnpm/yarn/pip/go/cargo・Docker・Homebrew・Xcode・ユーザーキャッシュ・ゴミ箱）
3. 削除候補をサイズ降順で提示（カテゴリ / パス / サイズ / 削除して良い理由 / リスク / 復元可否 / コマンド）
4. 削除するカテゴリをユーザーが選択（リスク中はデフォルト非選択）
5. 承認カテゴリのみ削除実行。公式クリーンコマンド優先、`rm` は厳格なガード付き
6. 解放容量・実行コマンド・失敗/スキップ項目をレポート

## 安全性

- **スキャンは読み取り専用** — `du`/`df`/`docker system df`/`brew --dry-run` 等のみ。破壊的コマンドを含まない
- 削除は承認カテゴリのみ。複数パスを束ねるカテゴリ・復元不能操作・リスク中はパス単位/実行直前の個別最終確認
- `rm` は `rm -rf -- <フルパス>` 固定、`/`・`$HOME`・`$HOME` 直下を対象にしない、symlink はスキップ
- ユーザーデータ領域（Documents・Desktop・クラウド同期・dotfiles・アプリ設定）は対象外
- sudo が必要な領域（apt/dnf/pacman キャッシュ・journal）は提示のみで実行しない
- Docker volumes はデータ消失リスクのため提示のみ

## 対象 OS

- macOS / Linux。`uname` で項目を出し分け、`command -v` で存在するツールのみスキャン（Homebrew は Linuxbrew も検出）

## 前提条件

- bash が利用できること。各クリーン対象ツール（npm/docker/brew 等）は任意（未インストールはスキップ表示）
